# 好友麻將（台灣十六張）

手機就能玩的麻將：跟電腦打（輕鬆／普通／高手）、找朋友連線打（空位電腦補）、教學模式、麻將教室、英雄榜。
大字體、只要輸入名字（同一支手機自動記住）、LINE 連結自動用外部瀏覽器開。

網址：https://edupnewp29-web.github.io/mahjong/

## 功能
| 模式 | 說明 |
|---|---|
| 跟電腦打 | 三家電腦，三種程度；一圈／二圈／一將；自動存檔可繼續 |
| 教學模式 | ★ 建議打哪張＋理由、還差幾張聽牌、聽哪些牌剩幾張、吃碰建議、放槍危險提醒；可攤開電腦的牌 |
| 找朋友打 | 開一桌 → 用 LINE 傳連結 → 朋友點開就坐下；空位由電腦補；斷線電腦代打 |
| 麻將教室 | 認識牌、胡牌結構、吃碰槓、流程、台數表、技巧；聽牌練習、打哪張練習 |
| 英雄榜 | 胡牌次數、累積分數、最大台數；線上名單、邀請 |

## 規則
- 16 張、含花 144 張；留牌 16 張；莊家胡或流局連莊。
- 計分：底 30＋每台 10；莊家另加 1 台，連莊每次再加 2 台（連 n 拉 n）。
- 台數：見遊戲內「台數表」（js/core.js `scoreHand`）。

## 檔案
- `js/core.js` 規則引擎（胡牌、聽牌、向聽、算台、對局流程；以種子＋動作紀錄重建，連線每台手機算出同一局）
- `js/ai.js` 電腦對手與教學建議，`js/table.js` 牌桌，`js/tiles.js` 牌面
- `js/online.js` Firebase，`js/app.js` 選單、名字、英雄榜，`js/lessons.js` 教室
- `firestore.rules` 貼到 Firebase → Firestore → 規則
